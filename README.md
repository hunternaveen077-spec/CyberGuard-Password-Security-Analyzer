# 🛡️ CyberGuard - Password Security Analyzer

A beginner-friendly Python tool that analyzes password strength using basic security checks.

## 🚀 Features

- Checks password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Gives a security score
- Provides suggestions to improve weak passwords

## 🛠️ Technologies Used

- Python 3
- String handling
- Conditional statements
- Basic security concepts

## ▶️ How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Run:

```bash
python cyberguard.py
Enter a test password when prompted.
📊 Example

Suggestions for improvement

This project performs basic local password-strength checks for educational purposes. It does not determine whether a password has been exposed in real-world data breaches.
